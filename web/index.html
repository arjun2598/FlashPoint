FlashPoint

A limit order book and matching engine in C++20, compiled to WebAssembly. This is the same engine the tests and benchmarks run against, not a reimplementation. It is matching orders on your machine, in this tab.

Source on GitHub · loading…

One command per line. # is a comment, ## is a heading. The script below is the tour the terminal demo runs by default: edit it and run it again.

Commands 
add <id> <buy|sell> <price|market> <qty> [gtc|ioc|fok]
cancel <id>
modify <id> <price> <qty>
show [depth]

Random order flow around a drifting mid: passive adds, cancels, modifies and a minority of aggressive orders that cross the spread. The same seed always produces the same run.

Built with Emscripten from the same source as the native binaries. The engine needed no changes to run here: no I/O, no threads, no platform calls, and events already go to a caller-supplied sink.
